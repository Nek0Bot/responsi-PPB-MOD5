# StudyMate PWA

Aplikasi manajemen tugas mahasiswa berbasis React + Vite + PWA.

## Fitur
- Dashboard ringkasan tugas
- CRUD tugas kuliah
- Profil mahasiswa
- Halaman Tentang
- LocalStorage
- Installable PWA dan offline cache

## Menjalankan
```cmd
npm.cmd install
npm.cmd run dev
```

## Build
```cmd
npm.cmd run build
npm.cmd run preview
```

Data tugas dan profil disimpan di LocalStorage browser.
